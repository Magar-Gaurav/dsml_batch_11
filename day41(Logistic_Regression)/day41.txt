# Day 41: Logistic Regression

## What is Logistic Regression?
- Logistic Regression is a supervised machine learning algorithm.
- It is used for Classification problems.
- It predicts categorical outcomes instead of continuous values.
- The output is generally:
  - 0 = False / No / Negative
  - 1 = True / Yes / Positive

----------------------------------------

## Why not Linear Regression?

Linear Regression predicts continuous values.

Examples:
- House Price
- Salary
- Temperature

Classification problems require probabilities between 0 and 1.

Therefore Logistic Regression uses the Sigmoid Function.

----------------------------------------

## Sigmoid Function

Formula:

P = 1 / (1 + e^-x)

Properties:
- Output ranges from 0 to 1
- Converts any real number into probability
- Produces an S-shaped curve

Decision Rule:
Probability > Threshold (usually 0.5)
→ Class = 1

Otherwise
→ Class = 0

## Linear Regression vs Logistic Regression

Linear Regression
- Predicts unlimited values
- Best for regression

Logistic Regression
- Predicts probability
- Best for classification

Applied sigmoid function to convert predictions into probabilities.
