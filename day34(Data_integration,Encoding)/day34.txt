1. Methods of Data Integration
Data integration is the process of combining data from multiple sources into a single, unified view.

Types:
- Virtual Integration
- API Integration
- ETL Integration (Extract, Transform, Load)


2. Data Encoding
Encoding is the process of converting categorical (text) data into numerical values so that machine learning algorithms can understand it.

Types:
- Label Encoding
- One-Hot Encoding
